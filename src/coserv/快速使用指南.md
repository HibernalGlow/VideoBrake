# Coserv - 快速使用指南

## 快速开始：只生成图片供 Gemini 识别

### 最简单的使用方式

```bash
# 1. 扫描文件夹并生成图片（默认不生成 JSON）
python cli.py scan "D:\Videos\Cosplay"

# 或处理单个视频文件
python cli.py scan "D:\Videos\video.mp4"

# 结果：在 D:\Videos\Cosplay\coserv_output\frames_时间戳\ 生成图片
#      或 D:\Videos\coserv_output\视频名\ 生成图片（单文件模式）
```

### 2. 在 Gemini 中识别并重命名

将生成的图片文件夹拖入 Gemini，使用以下 prompt：

```
识别这些 Cosplay 图片中的角色和作品，为每个文件夹生成 PowerShell 重命名命令。

输出格式：Rename-Item "文件夹名" "[角色名_作品名] 文件夹名"
如果无法识别：Rename-Item "文件夹名" "[未知角色_未知] 文件夹名"
```

### 3. 执行重命名

复制 Gemini 生成的命令，在 PowerShell 中执行：

```powershell
cd "D:\Videos\Cosplay"
# 粘贴 Gemini 生成的命令
```

完成！文件夹将被重命名为 `[角色名_作品名] 原文件夹名`

## 可选配置

###调整图片数量和大小

```bash
# 每个文件夹提取 3 张图片，每张 30KB
python cli.py scan "路径" --max-frames 3 --image-size 30

# 只处理前 10 个文件夹（测试用，仅文件夹模式）
python cli.py scan "路径" --limit 10

# 处理单个视频文件
python cli.py scan "D:\Videos\specific_video.mp4" --max-frames 3
```

### 同时生成 JSON（用于后续自动化处理）

```bash
# 生成图片和 JSON
python cli.py scan "路径" --json

# 后续可以使用 identify.py 和 process.py 进行自动化处理
```

## 参数说明

| 参数           | 说明                                 | 默认值                 |
| -------------- | ------------------------------------ | ---------------------- |
| `target_dir`   | 目标文件夹路径或单个视频文件路径     | 必需                   |
| `--json`       | 保存 JSON 文件（默认不保存）         | 不保存                 |
| `--max-frames` | 每个文件夹/视频提取的图片数量        | 5                      |
| `--image-size` | 图片压缩目标大小（KB）               | 25                     |
| `--limit`      | 限制处理的文件夹数量（仅文件夹模式） | 无限制                 |
| `--output`     | 输出目录                             | 视频目录/coserv_output |

## 常见问题

**Q: 输出目录太深，可以改吗？**
A: 使用 `--output` 参数指定：`python cli.py scan "路径" --no-json --output "D:\output"`

**Q: 可以处理子文件夹的子文件夹吗？**
A: 目前只扫描一级子文件夹。如需递归，需要修改代码。

**Q: 重命名后如何撤销？**
A: PowerShell 命令：

```powershell
Get-ChildItem -Directory | Where-Object { $_.Name -match '^\[.+?\] (.+)$' } |
    Rename-Item -NewName { $_.Name -replace '^\[.+?\] (.+)$', '$1' }
```

**Q: 生成的图片可以删除吗？**
A: 重命名完成后可以删除整个 `coserv_output` 文件夹。
