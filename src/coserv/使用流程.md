# 🎯 完整使用流程（超简化版）

## 📋 完整工作流程

```
1️⃣ 提取关键帧 → 2️⃣ 用Gemini识别 → 3️⃣ 合并结果 → 4️⃣ 整理文件
   (prepare.py)    (手动+Gemini)    (merge_results.py)  (organize.py)
```

---

## 第一步：提取关键帧 ⚡

```bash
# 处理视频（每个视频提取3张关键帧）
python prepare.py "E:\BaiduNetdiskDownload\T38-049"

# 或限制数量测试
python prepare.py "E:\BaiduNetdiskDownload\T38-049" --limit 5
```

**结果：**

- 生成 `output/pending.json`（待识别清单）
- 每个视频在 `output/视频名/frames/` 下有 3 张截图

---

## 第二步：用 Gemini 识别 🤖

### 2.1 生成识别指令

```bash
python generate_prompt.py
```

会输出完整的 prompt 和文件路径！

### 2.2 启动 Gemini CLI

```bash
cd output
gemini
```

### 2.3 在 Gemini 中识别

复制生成的 prompt，在 Gemini CLI 中对话：

```
你: [粘贴 generate_prompt.py 输出的内容]

Gemini: [会分析图片]

你: 请按照我要求的格式，将结果保存到指定的 JSON 文件
```

### 2.4 手动创建 result.json

对于**每个视频文件夹**，创建 `result.json`：

**示例 1：成功识别**

```json
{
  "character": "胡桃",
  "source": "原神",
  "confidence": "high"
}
```

**示例 2：未识别**

```json
{
  "character": "未知",
  "source": "未知",
  "confidence": "low"
}
```

保存位置：`output/视频名/result.json`

---

## 第三步：合并结果 📦

```bash
python merge_results.py
```

**作用：**

- 读取所有 `output/*/result.json`
- 合并生成 `output/results.json`
- 显示识别统计

**输出示例：**

```
✓ T38-049: 胡桃 (原神)
✓ video_002: 甘雨 (原神)
⏭ video_003: 未找到 result.json

总视频数: 3
✓ 已识别: 2
⏭ 待识别: 1
```

---

## 第四步：整理文件 📂

```bash
# 测试模式（不移动文件）
python organize.py "E:\BaiduNetdiskDownload\T38-049" --dry-run

# 正式整理
python organize.py "E:\BaiduNetdiskDownload\T38-049"
```

**结果：**

```
E:\BaiduNetdiskDownload\T38-049\
├── 胡桃(原神)/
│   └── T38-049.mp4
├── 甘雨(原神)/
│   └── video_002.mp4
└── 未识别角色/
    └── video_003.mp4
```

## 💡 使用技巧

### 技巧 1：批量处理

处理大量视频时分批进行：

```bash
# 第一批：5个视频
python prepare.py "视频目录" --limit 5
python generate_prompt.py
# [识别...]
python merge_results.py
python organize.py "视频目录"

# 第二批：再5个
python prepare.py "视频目录" --limit 10
# [继续...]
```

### 技巧 2：快速查看截图

```bash
# Windows
explorer output\视频名\frames

# 或用图片查看器批量查看
start output\视频名\frames\frame_01.jpg
```

### 技巧 3：批量创建 result.json

如果很多视频都是同一个角色，可以：

1. 创建一个模板 `template.json`：

   ```json
   {
     "character": "胡桃",
     "source": "原神",
     "confidence": "high"
   }
   ```

2. 批量复制（PowerShell）：
   ```powershell
   Copy-Item template.json output\video1\result.json
   Copy-Item template.json output\video2\result.json
   ```

### 技巧 4：修正错误识别

如果识别错了，只需：

1. 修改对应文件夹的 `result.json`
2. 重新运行 `python merge_results.py`
3. 重新运行 `python organize.py`

## ❓ 常见问题

### Q: Gemini 识别不准确怎么办？

**A:** 手动修改 `result.json`，然后重新合并。

### Q: 可以跳过某些视频吗？

**A:** 不创建该视频的 `result.json`，合并时会标记为 "待识别"。

### Q: 如何重新处理某个视频？

**A:**

1. 删除 `output/视频名/` 文件夹
2. 重新运行 `prepare.py`
3. 重新识别

### Q: 识别结果保存在哪里？

**A:**

- 单个结果：`output/视频名/result.json`
- 合并结果：`output/results.json`
