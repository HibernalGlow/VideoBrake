## 🎯 技术亮点

### 1. 三重过滤机制

```
原始视频
   ↓
[场景检测] → 提取不同机位画面
   ↓
[人脸过滤] → 过滤无人脸画面
   ↓
[视觉去重] → 剔除相似画面
   ↓
最优帧集合
```

### 2. 智能降级策略

- 场景检测失败 → 均匀采样
- JSON 解析失败 → 文本解析
- 识别失败 → 归入"未识别"文件夹

### 3. 用户友好设计

- 测试模式（--dry-run）
- 限量处理（--limit）
- 进度可视化（tqdm）
- 详细统计报告

### 4. 高度可配置

- 所有参数集中在 `config.py`
- 支持环境变量
- 可切换移动/复制模式

## 📊 性能指标

### 理论处理速度

- 场景检测：~15 秒/视频（取决于长度）
- 人脸检测：~0.1 秒/帧
- AI 识别：~3-5 秒/视频
- **预估总速度**：~20-30 秒/视频

### 准确率影响因素

✅ **正向因素**：

- 视频质量高
- 有清晰人脸特写
- 角色知名度高

❌ **负向因素**：

- 视频模糊、抖动
- 只有远景、背影
- 小众角色

### 💡 最佳实践

1. 先用 `--limit 3` 测试效果
2. 根据结果调整 `config.py` 参数
3. 分批处理大量视频（避免长时间运行）
4. 定期检查"未识别"文件夹
