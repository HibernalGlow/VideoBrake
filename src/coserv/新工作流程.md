# 🔄 新工作流程说明

## 📋 工作流程概览

```
┌─────────────────────────────────────────────────────┐
│  1️⃣ 前期准备 (prepare.py)                           │
│  ✓ 自动扫描视频                                      │
│  ✓ 智能提取关键帧                                    │
│  ✓ 生成待识别清单                                    │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│  2️⃣ 人工识别 (使用 Gemini CLI)                       │
│  👤 用户查看提取的帧                                  │
│  🤖 使用 Gemini CLI 辅助识别                         │
│  ✍️ 手动创建 results.json                            │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│  3️⃣ 后期整理 (organize.py)                           │
│  ✓ 自动读取识别结果                                  │
│  ✓ 创建角色文件夹                                    │
│  ✓ 移动视频文件                                      │
└─────────────────────────────────────────────────────┘
```

## 🚀 详细步骤

### 步骤 1：前期准备

**运行前期脚本：**

```bash
python prepare.py "D:\Videos\Cosplay"
```

**可选参数：**

```bash
# 限制处理数量（用于测试）
python prepare.py "D:\Videos\Cosplay" --limit 5

# 指定输出目录
python prepare.py "D:\Videos\Cosplay" --output my_output
```

**脚本会做什么：**

1. 扫描视频目录，找到所有视频文件
2. 对每个视频：
   - 场景检测找到不同镜头
   - 人脸检测过滤无人脸画面
   - 视觉去重剔除相似帧
   - 保存关键帧到 `output/视频名/frames/` 目录
3. 生成 `output/pending.json` 待识别清单

**输出示例：**

```
output/
├── pending.json              # 待识别清单
├── cosplay_video_001/
│   └── frames/
│       ├── frame_01.jpg
│       ├── frame_02.jpg
│       └── frame_03.jpg
├── cosplay_video_002/
│   └── frames/
│       ├── frame_01.jpg
│       └── frame_02.jpg
└── ...
```

---

### 步骤 2：人工识别

#### 方法 A：使用 Gemini CLI 辅助（推荐）

1. **进入输出目录：**

   ```bash
   cd output
   ```

2. **启动 Gemini CLI：**

   ```bash
   gemini
   ```

3. **在对话中识别角色：**

   ```
   你: 我有一些 Coser 照片需要识别角色，请帮我识别这些图片中的角色：
       cosplay_video_001/frames/frame_01.jpg
       cosplay_video_001/frames/frame_02.jpg

   Gemini: [分析图片后给出答案，例如]
           这些图片中的角色是原神中的优菈（Eula）

   你: 谢谢！下一个视频：
       cosplay_video_002/frames/frame_01.jpg

   Gemini: [继续识别...]
   ```

4. **记录识别结果到 Excel 或文本（临时）**

5. **创建 `results.json` 文件**

#### 方法 B：纯手工识别

1. 打开 `output/` 目录
2. 逐个查看 `*/frames/` 中的图片
3. 根据自己的认知识别角色
4. 记录结果

#### 创建 results.json

参考 `results_template.json`，创建 `output/results.json`：

```json
[
  {
    "video_name": "cosplay_video_001",
    "video_path": "D:\\Videos\\Cosplay\\cosplay_video_001.mp4",
    "frames_dir": "cosplay_video_001/frames",
    "frames": ["cosplay_video_001/frames/frame_01.jpg"],
    "frame_count": 3,
    "status": "identified",
    "character_info": {
      "character": "优菈",
      "source": "原神"
    }
  },
  {
    "video_name": "cosplay_video_002",
    "video_path": "D:\\Videos\\Cosplay\\cosplay_video_002.mp4",
    "frames_dir": "cosplay_video_002/frames",
    "frames": ["cosplay_video_002/frames/frame_01.jpg"],
    "frame_count": 2,
    "status": "identified",
    "character_info": {
      "character": "2B",
      "source": "尼尔:自动人形"
    }
  }
]
```

**字段说明：**

- `status`:
  - `"identified"` - 已识别，会按角色整理
  - `"pending"` - 未识别，会移动到"未识别角色"文件夹
  - `"skipped"` - 跳过，不处理
- `character_info`: 角色信息
  - `character`: 角色名
  - `source`: 作品名

### 步骤 3：后期整理

**测试模式（推荐先测试）：**

```bash
python organize.py "D:\Videos\Cosplay" --dry-run
```

**正式整理：**

```bash
python organize.py "D:\Videos\Cosplay"
```

**可选参数：**

```bash
# 指定结果文件路径
python organize.py "D:\Videos\Cosplay" --results my_results.json
```

**脚本会做什么：**

1. 读取 `output/results.json`
2. 根据识别结果：
   - 创建角色文件夹（如："优菈(原神)"）
   - 移动或复制视频到对应文件夹
   - 未识别的放入"未识别角色"文件夹
3. 生成整理报告

**整理后目录结构：**

```
D:\Videos\Cosplay\

│   ├── cosplay_video_001.mp4
│   └── cosplay_video_005.mp4

│   └── cosplay_video_002.mp4
├── 甘雨(原神)/

│   └── cosplay_video_007.mp4
└── 未识别角色/
    └── cosplay_video_004.mp4
```

## 💡 使用技巧

### 1. 批量处理策略

**首次使用（小批量测试）：**

```bash
# 只处理 3 个视频
python prepare.py "视频目录" --limit 3
# 识别后...
python organize.py "视频目录" --dry-run
```

**确认无误后扩大规模：**

```bash
# 处理 20 个视频
python prepare.py "视频目录" --limit 20
# 识别后...
python organize.py "视频目录"
```

**最后全量处理：**

```bash
python prepare.py "视频目录"
# 识别后...
python organize.py "视频目录"
```

### 2. 分批识别

如果视频很多，可以分批处理：

```bash
# 第一批：5 个视频
python prepare.py "视频目录" --limit 5 --output batch1
# 识别 batch1...
python organize.py "视频目录" --results batch1/results.json

# 第二批：再处理 5 个
python prepare.py "视频目录" --limit 10 --output batch2
# 识别 batch2...
python organize.py "视频目录" --results batch2/results.json
```

### 3. 快速编辑 results.json

**使用辅助工具：**

1. 将 `pending.json` 复制为 `results.json`
2. 使用文本编辑器批量替换
3. 或使用 Excel 打开（需转换）

**快捷命令（PowerShell）：**

```powershell
# 复制模板
copy output\pending.json output\results.json

# 编辑
notepad output\results.json
```

### 4. 识别未识别的视频

对于 `status: "pending"` 的视频，可以：

- 改为 `"skipped"` 跳过不处理
- 或保持 `"pending"`，会自动移动到"未识别角色"文件夹

## ⚙️ 配置调整

如果提取的帧不理想，可以调整 `config.py`：

### 提取更多帧

```python
MAX_FRAMES_PER_VIDEO = 15  # 默认 10
SCENE_THRESHOLD = 20.0     # 降低阈值，检测更多场景
```

### 降低人脸检测要求

```python
FACE_DETECTION_CONFIDENCE = 0.3  # 默认 0.5
MIN_FACE_SIZE_RATIO = 0.05       # 默认 0.1
```

### 增加帧的多样性

```python
HASH_DIFF_THRESHOLD = 15  # 默认 10，值越大保留越多不同的帧
```

## 🔧 故障排除

### Q: prepare.py 没有提取到帧

**A:**

- 检查视频是否包含人脸
- 降低 `FACE_DETECTION_CONFIDENCE`
- 查看 `output/视频名/frames/` 确认是否有输出

### Q: 不知道如何创建 results.json

**A:**

- 参考 `results_template.json` 模板
- 或复制 `pending.json` 后修改
- 只需改 `status` 和 `character_info` 字段

### Q: organize.py 提示找不到结果文件

**A:**

- 确认 `output/results.json` 存在
- 或使用 `--results` 指定路径
