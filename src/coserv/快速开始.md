# 🚀 快速开始指南

## 第一步：安装依赖

打开终端，进入项目目录，运行：

```bash
cd d:\1VSCODE\Projects\PackU\VideoBrake\src\coserv
pip install -r requirements.txt
```

## 第二步：配置 API Key

1. **获取 Gemini API Key**

   - 访问：https://makersuite.google.com/app/apikey
   - 登录 Google 账号
   - 点击 "Create API Key"
   - 复制生成的 API Key

2. **创建配置文件**

   ```bash
   copy .env.example .env
   ```

3. **编辑 .env 文件**
   ```env
   GEMINI_API_KEY=你刚才复制的密钥
   ```

## 第三步：测试运行

### 方法 1：使用启动脚本（推荐）

双击 `启动.bat`，选择模式 1（测试模式）

### 方法 2：命令行

```bash
# 先测试单个视频（最安全）
python main.py "D:\你的视频文件夹" --single "某个视频.mp4" --dry-run

# 测试模式（处理3个视频，不移动文件）
python main.py "D:\你的视频文件夹" --dry-run --limit 3

# 如果测试结果满意，正式运行
python main.py "D:\你的视频文件夹" --limit 10
```

## 第四步：查看结果

系统会自动创建角色文件夹，例如：

```
D:\你的视频文件夹\
├── 优菈(原神)/
│   ├── video1.mp4
│   └── video2.mp4
├── 2B(尼尔自动人形)/
│   └── video3.mp4
└── 未识别角色/
    └── video4.mp4
```

## ⚙️ 常用参数

| 参数          | 说明                 | 示例                 |
| ------------- | -------------------- | -------------------- |
| `--dry-run`   | 测试模式，不移动文件 | `--dry-run`          |
| `--limit N`   | 只处理前 N 个视频    | `--limit 5`          |
| `--single`    | 只处理单个视频       | `--single video.mp4` |
| `--recursive` | 递归处理子目录       | `--recursive`        |

## 🔧 调优技巧

### 如果人脸检测不到

编辑 `config.py`：

```python
FACE_DETECTION_CONFIDENCE = 0.3  # 降低置信度（默认 0.5）
MIN_FACE_SIZE_RATIO = 0.05       # 降低最小人脸比例（默认 0.1）
```

### 如果提取的帧太少

编辑 `config.py`：

```python
MAX_FRAMES_PER_VIDEO = 15        # 增加最大帧数（默认 10）
SCENE_THRESHOLD = 20.0           # 降低场景检测阈值（默认 27.0）
```

### 如果识别不准确

编辑 `config.py`：

```python
HASH_DIFF_THRESHOLD = 15         # 增加去重阈值（默认 10），保留更多样化的帧
```

## ❓ 常见问题

### Q: API 请求失败？

**A:** 检查：

1. API Key 是否正确
2. 网络是否能访问 Google
3. 是否需要配置代理（在 .env 中设置 `HTTP_PROXY`）

### Q: 没检测到人脸？

**A:**

1. 检查视频质量（太模糊、太暗会影响检测）
2. 降低 `FACE_DETECTION_CONFIDENCE`
3. 查看 `test_output/` 目录确认提取的帧

### Q: 识别率低？

**A:**

1. 增加 `MAX_FRAMES_PER_VIDEO`
2. 确保视频中有清晰的人脸特写
3. 使用 `--single` 测试单个视频，看原始响应

### Q: 想复制文件而不是移动？

**A:** 编辑 `config.py`：

```python
MOVE_FILES = False  # 改为 False
```
